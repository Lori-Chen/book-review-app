
# 书评阅读APP - 产品需求文档

## 1. Product Overview

书评阅读APP是一款专注于书籍发现、阅读和分享的移动端应用，为用户提供丰富的书籍资源、专业的书评内容和便捷的社交互动功能。

- 主要目标：帮助用户发现优质书籍、记录阅读心得、分享阅读体验
- 目标用户：阅读爱好者、学生、职场人士等所有喜欢阅读的人群

## 2. Core Features

### 2.1 User Roles

| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 普通用户 | 邮箱/第三方登录 | 浏览书籍、写书评、管理个人书架、关注其他用户 |

### 2.2 Feature Module

1. **登录页**：邮箱密码登录、第三方登录、注册入口
2. **首页**：搜索、标签导航、推荐书籍、分类图标、banner、大家都在看书单
3. **书籍详情页**：书籍信息展示、评分、书评、相关推荐
4. **搜索与发现页**：搜索、筛选排序、热门分类、书籍列表
5. **个人主页**：用户信息、我的评价/书架/收藏
6. **写书评页**：星级评分、标题内容输入、标签选择、发布设置

## 3. Core Process

用户主要使用流程：

1. 用户登录 → 首页浏览 → 发现感兴趣的书籍 → 查看书籍详情 → 阅读书评 → 添加到书架/写书评
2. 用户登录 → 发现页搜索 → 筛选书籍 → 查看详情
3. 用户登录 → 个人主页 → 查看我的评价/书架/收藏
4. 用户登录 → 写书评 → 选择书籍 → 评分 → 撰写内容 → 发布

## 4. User Interface Design

### 4.1 Design Style

- **主色调**：青蓝色/浅蓝色 (#4A90E2, #5DADE2)
- **辅助色**：黄色/橙色 (#F39C12, #E67E22) - 用于评分星标
- **按钮风格**：圆角设计，主按钮用青蓝色填充，次要按钮用边框样式
- **字体**：现代无衬线字体，标题加粗，正文清晰易读
- **布局风格**：卡片式设计，移动端优先，375px设计稿
- **图标风格**：简洁线性图标，配色协调

### 4.2 Page Design Overview

| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 登录页 | 整体布局 | 垂直居中布局，表单区域卡片化，清晰的输入提示 |
| 首页 | 顶部区域 | 搜索框 + 标签导航，紧凑而有序 |
| 首页 | 内容区域 | 推荐卡片、分类图标、banner、书单列表，滚动布局 |
| 首页 | 底部导航 | 固定底部，图标+文字，当前页高亮显示 |
| 书籍详情页 | 头部区域 | 大尺寸封面 + 书籍信息，视觉层次分明 |
| 书籍详情页 | 内容区域 | 分段展示出版信息、简介、评分、书评，可滚动 |
| 搜索与发现页 | 筛选区域 | 排序标签、评分滑块、分类标签，交互友好 |
| 个人主页 | 头部区域 | 用户头像、昵称、简介，数据统计卡片 |
| 个人主页 | 内容区域 | 标签切换，列表展示，清晰的信息组织 |
| 写书评页 | 输入区域 | 书籍信息卡片、评分选择、文本输入框，简洁高效 |

### 4.3 Responsiveness

- **移动端优先**：375px设计稿，适配主流手机屏幕
- **响应式适配**：支持320px-414px宽度范围
- **触摸优化**：按钮和可点击区域尺寸适中，便于触摸操作

### 4.4 3D Scene Guidance

本项目不涉及3D场景。
